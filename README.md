# Т-Лига · самостоятельное frontend-приложение

Мобильное React-приложение согласованной концепции Т-Лиги: на компьютере оно отображается в телефонной рамке, на телефоне — на весь экран. Это самостоятельное приложение, не встраивание в Т-Инвестиции и не Telegram WebApp. Исходные HTML и документация проекта не заменены.

## Запуск

Нужен Node.js 20.19+ (проверяется на 20.20.2) и npm.

```sh
npm ci
npm run dev
```

Открыть URL, напечатанный Vite, обычно `http://127.0.0.1:5173`. Первый запуск требует локального dev-server: двойной щелчок по HTML не запускает service worker. MSW включён и в production preview, поскольку реального backend нет.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
npm run test:e2e
npm run storybook
npm run build-storybook
npm run format
```

Для Playwright при отсутствии браузера: `npx playwright install chromium`. Storybook работает на порту 6006.

## Что работает

Выбор Макса/Льва/Чилла, знакомство и сохранённые разрешения; контекст действий и сценарный чат; явный торговый план с предпросмотром, подтверждением/отклонением и версиями; ручные виртуальные покупки/продажи лотами с комиссиями; история; арена и профили с серверной редакцией закрытых данных; сквады, приглашения, обсуждение, утверждение планов, одобряемые допвзносы, полный выход/архив; сезонные награды; сравнение агентов; подписки и демо-пакеты.

Явное поручение агенту в чате: `Продай SBER 1 лот` или `Купи GOLD 1 лот`. Нужны сохранённое знакомство, активный агент и достаточные разрешения/бюджет. Неоднозначная просьба «может поменяем портфель?» вызывает уточнения, а не торговлю. Маржинальные сделки/шорты не поддержаны симулятором и не подменяются покупкой за наличные.

## Данные и демонстрационные границы

Все HTTP-запросы `/api/*` перехватывает MSW. Mock-server имеет собственную базу в `localStorage` (`tliga-mock-server-v1`), отдельно от Zustand-настроек интерфейса. TanStack Query хранит и обновляет полученные серверные данные; клиентский store не дублирует деньги, позиции или права.

Данные создаются с фиксированным seed Faker. Обычные аналитические задачи учитываются по месячному периоду с лимитом выбранного пакета; уточнение текущей задачи не списывается повторно. Глубокие квоты остаются характеристикой предлагаемого тарифа: отдельный GPU-metering в макете не реализован. Котировки, лоты, графики, комиссии 0,3%, условный налог выхода 13%, пользователи, подтверждения других участников и тарифы — учебные примеры, не банковские условия. Денежные расчёты — `decimal.js`, денежный контракт API — строка, не float. Графики получают number только для визуализации.

Нет LLM, реального MCP, брокерского счёта, приёма взносов, платежей, доходности в будущем или фонового рыночного мониторинга. Выбор платного пакета меняет только mock-базу. Прогнозы прибыли в сравнении агентов не строятся. Выход из сквада — полный: снимок оценки доли с убытками/расходами; результат не поступает на личный реальный счёт. Взнос не применяется до отдельного демо-одобрения команды; новые units выпускаются по текущей NAV, без присвоения прошлой прибыли.

## Сброс и ошибки

- `/?reset=1` сбрасывает mock-базу перед запуском.
- `/?mockError=1` возвращает API-ошибки для проверки UI. Удалить параметр и повторить запрос.
- Клиентская тема/активный сквад хранятся в `tliga-client-settings-v1`.

## Структура и версии

Архитектура FSD и контракты: [docs/architecture.md](docs/architecture.md). Слои: app → pages → widgets → features → entities → shared. Публичные API entity-slices — `index.ts`; общие DTO/HTTP находятся в shared/api, mock-исполнение — src/mocks. UI создаётся React-компонентами, исходный HTML не вставляется через iframe или dangerouslySetInnerHTML.

Зафиксированы Node20-совместимые стабильные линии: React 19.1.1, Vite 6.4.1, TypeScript 5.9, React Router 7, TanStack Query 5, Zustand 5, Vitest 3, Storybook 8.6.19. `package-lock.json` закрепляет конкретные разрешённые версии. Новейшие major не подключались без проверки совместимости.

## Передача команде

Передавать исходный каталог без `node_modules`, затем `npm ci`. Для демонстрации сборки — `npm run build && npm run preview`. Для размещения SPA сервер должен возвращать `index.html` на клиентские маршруты и раздавать `/mockServiceWorker.js`. Публикация и доступ к реальным сервисам в эту работу не входят.

## Соответствие исходному макету: восстановленные сценарии

Черновик знакомства хранится в клиентском Zustand store: цель, приоритет, горизонт, бюджет, режим, инструменты, лимиты и стиль. Его можно отложить и продолжить после перезагрузки; рабочие разрешения меняются только при явном применении.

Общий сквад имеет отдельные виртуальные деньги, позиции и заявки. Координатор создаёт конечный учебный план покупки ОФЗ, проверяет версию, общие лимиты и согласие каждого участника. Подтверждение за себя не выдаёт согласие друзей; отдельная демонстрационная кнопка явно симулирует согласования. Один исполнитель изменяет только общий портфель, повтор не дублирует заявку. При полном выходе сохраняется собственный снимок оценки и расчётной выплаты, а не остаток всей команды.

Новые поля добавляются к сохранённому mock-состоянию без сброса данных. Применение темы/титула из награды проверяет факт получения на стороне mock-API; просмотр платной награды не открывает её. При HMR изменения обработчиков MSW обновляются без сохранения старого набора endpoint-логики.
